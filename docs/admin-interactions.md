AI资源管理 → 企业资源 → 共享授权：选择单个资源，部门树/角色/员工搜索支持批量对象；部门只按直接归属生效，不包含未明确授权的下级。查看是基础权限，使用与编辑草稿包含查看；编辑不等于发布。共享按组织资源引用生效，凭据只留服务端。

使用授权提交前检查当前成员基础资格，以及助手/技能的模型、工具、知识、MCP依赖。角色/部门当前活跃成员每次最多200人；空组、超限或依赖不足会给出原因，未来成员仍在执行时验证。不会为使校验通过而自动授权依赖或复制连接凭据。外部连接页面必须明确选择要共享的连接资源或查询专家，不再连带批量扩权。

同一资源和对象的相同活动授权返回原记录，调整权限复用该记录；减少权限沿用既有撤权链。撤回只影响这条授权，其他角色、部门及公开发布仍可能提供访问，不承诺对象已完全失权。共享接口仍由服务端复核所有权与依赖，前端预检不是安全边界。
