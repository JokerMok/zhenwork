# 企业知识与业务专家

当前应用 `20261025-knowledge-experts-v3` / `76806bb96381b07523ebc3d9215325bb1532d354`，基线 `20261025-resource-efficiency-v4`。本轮复用 RuoYi 知识文档、索引、版本、授权、专家和 Office 工具，不增加常驻服务、向量数据库或公共第三方预览服务。

## 员工路径

办公工作台 → 知识：个人、组织来源及查看/使用/编辑权限分别展示；个人新建知识库默认私有。上传后显示解析/索引状态和生效版本；运行中状态有界刷新，失败可重试。支持文档分页；按知识库/文件名/SHA 复用相同上传，不重复创建资料或索引。显式上传新版本仍检查 expectedVersion；内容未变化时复用原版本。

新任务/会话输入区 → 本次知识范围：选择整库时使用当前有权访问的索引版本；选择文件时固定文档身份和版本。不选资料是明确的空范围；尚未配置任务范围时沿用当前授权目录和专家默认指引。固定文件和整库选择互斥于同一库，避免意外扩大范围。已创建任务的选择保存在 Host 的员工私有元数据中，刷新、重新登录仍可恢复；不会复制企业凭据或知识正文到个人配置。

检索工具按任务范围执行；选择某文件后不能借模型参数改查其他库。每次调用、生成带引用的成果、发送后续任务均检查当前授权。管理员撤销后不能凭旧范围继续执行或打开原文；员工可修改知识范围后继续其他工作。

回答中的原文链接进入知识页的对应 documentId/version/chunk。显示实际章节、工作表、页码或行片段；不能生成不存在的定位。本站知识引用使用正常浏览器标签页打开，避免认证页面被送入内置浏览面板。旧引用只打开原版本，不自动替换成新内容；当前不可访问时明确提示。原文件下载沿用服务端授权，不依赖 Core。

## 管理员路径

AI 资源管理 → 企业资源 → 知识库：新建、上传、查看索引及失败原因，按既有激活、共享或独立发布审核机制授权。

同页选择助手：填写名称、专家用途、模型和指令，组合已有知识、Skill、工具和 MCP。保存专家草稿后，在同一编辑流程检查依赖、激活已保存版本、设置授权对象。未保存的修改不能直接激活；保存后可正常关闭，不再误报未保存。员工点击“使用”后，首页保留明确所选专家，直到异步目录完成且选中该专家才消费导航请求；此期间不能以默认助手代发任务。

激活及发布在服务端检查依赖；知识依赖须有可用索引，MCP须为已验证可用连接。共享仍使用既有依赖预检，专家和依赖必须分别有相应使用授权，不隐式扩大范围。停用、撤回、更新、权限变化沿用现有运行时和调用时复核。查询专家继续使用已有获授权业务连接，产品专家使用知识资料，两者复用同一执行链。

## 数据与版本边界

- 10MiB上传、每库50份文档、解析字符/页数/OCR/超时及单索引执行保护保持。仅主动上传或已配置的受控目录可入库，不扫描员工电脑或整台服务器。
- 索引成功才更新 indexed_version；失败保留原生效版本，新版本不会冒充已生效。历史版本的原文件和正文保留；删除时取消索引任务并清除派生索引，原文/检索/下载立即按删除及当前权限拒绝。
- 检索继续使用当前有界 PostgreSQL 词法方案；文档、网页和业务接口来源分别标注，不把参数推断当事实。资料冲突、条件、单位与版本应分别列明，缺独立需求时不声称真实客户符合性。
- 目录、索引状态、原文和既有成果读取通过 Host/RC2，不唤醒 Core。执行任务仍按原 Core1、启动1、队列2、等待180秒、闲置120秒策略。

## 验收

代码定向检查包括员工任务范围隔离、固定版本与越界引用、重复上传、知识就绪与专家依赖检查。真实员工上传/专家问答/打开原文/生成报告和表格/继续修改/更新/撤权结果以本轮私有 `.codex/knowledge-experts/acceptance-report.md` 和服务器 VERIFIED.json 为准；构建和单元用例不替代业务验收。

共享目录尚无本轮指定真实路径，不新增或猜测目录。独立客户符合性仍待真实独立需求资料。
