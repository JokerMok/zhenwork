# 企业外部数据连接与查询专家

本模块面向单企业私有部署。不同实际业务单位使用独立连接、凭据和资源授权；它不是多租户 SaaS。接口方法、参数及官方依据见 [接口映射](external-query-mapping.md)。真实上游联调结果应查当前 `PROJECT.md` 与发布 `VERIFIED.json`，代码和协议测试不代表凭据已取得授权。

## 管理员配置

管理后台的“AI 资源管理 → 外部数据连接”集中维护连接。依次填写连接名称、连接器、实际业务单位、测试/正式环境、服务地址和该单位取得的访问凭据；勾选目录内允许开放的只读方法。地址与环境受连接器固定规则校验，不能填任意 URL。未确认的上游方法会标注限制，不因在目录中出现就视为可调用。

优废大屏使用该系统的 JWT，服务端直接放入 `Authorization`，不添加 `Bearer`。国家危险废物平台使用接入单位取得的物联网 token；服务端生成 SM4 密文、随机 nonce、秒级时间戳和 SM3 签名。员工和模型都不需要接触这两类凭据，也不能从工具参数提供上游 token。

凭据输入框不回显已保存值。留空保存普通字段保留原凭据；输入新值表示替换；只有勾选显式清除才删除。凭据、环境、地址或业务单位变动后必须重新验证。国家平台验证调用单位信息查询，核对返回的企业 ID、名称和统一社会信用代码；不要把业务单位显示名称当成已验证的上游企业身份。

验证后按业务范围启用连接。查询专家复用管理员设置的默认模型，绑定所选连接的 MCP 资源。员工必须同时拥有助手以及所用连接的查看/使用权限；可按员工、角色和部门授权。独立 MCP 资源也可以单独授权给现有助手使用。绑定助手不自动绕过各连接授权，新增一个业务单位连接也不会自动授权现有员工。

## 员工使用

员工在正常工作台选择已授权的查询专家，直接提出业务问题；不配置地址、API 或凭据。对应业务能力必须实际调用工具。一个问题包含多项查询时分别获取数据，相同条件避免重复查询。未实现的方法、接口不支持的任意日期/企业过滤、未提供的统计口径应明确说明，不补造数据。

回答应包含数据源、环境、连接对应单位、查询方法、查询时间以及接口实际提供的统计期间和单位。求和、比例、环比使用现有计算/Python/办公工具，不能凭模型心算。跨系统比较先核对企业、日期、单位和口径；无法对齐时并列展示并说明差异。需要文件时继续使用工作台现有成果生成、预览、下载和版本功能。

空数据、查询失败和部分成功分别表达。HTTP 成功不能替代业务成功；国家平台严格要求 HTTP200 且业务 code 为数字或字符串1000。优废业务成功条件单独以其合同和实际凭据验证，不套用国家平台代码。无可靠登录/刷新协议时由管理员安全更换凭据，不自动猜测续期。

## 服务端边界与维护

查询执行位于 RC2/RuoYi，复用既有 MCP Streamable HTTP 代理、会话身份复核、资源 ACL、后台授权和助手配置。网页本轮接入同一 MCP 逻辑；桌面或后续入口可以复用该逻辑，本轮不构建或验收桌面安装包。

连接凭据使用现有 AES-256-GCM 服务加密保存，主密钥位于数据库外的私有配置。MCP 到工作台的受控会话身份和 MCP 到业务系统的上游凭据独立。工具只暴露固定方法与严格参数 schema，不接受任意 SQL、URL、请求头或自由请求体。调用前与返回前检查连接状态、业务单位绑定和当前资源授权。审计记录身份、连接、方法、版本、结果及耗时，不记录原始凭据或业务响应。

连接配置及密文包含在既有数据库一致性备份，解密主密钥沿原私有配置备份。更新先审阅发布 manifest、迁移链、备份和兼容回滚审核，再按 [腾讯云维护流程](../deploy/tencent/README.md) 激活；只操作 ZhenWork。应用回滚不撤销数据库配置、授权或查询记录，不等于数据库回滚。

运行资源沿用现有每次最多1个员工 Core、启动并发1和空闲回收。连接器不为每个 HTTP 方法部署独立服务，不新增公网数据库、Docker 或业务凭据端口。国家平台请求依赖服务端正确校时；检查 `timedatectl show -p NTPSynchronized`。调用审计和连接最近验证错误用于定位凭据失效、业务拒绝、超时和格式变化；不要向聊天或公开 issue 粘贴 token。
