# 企业固危废数据专员标准能力包 v1

员工在[工作台](https://zhenwork.shizibandu.icu/#/workspace?section=abilities)的专家列表选择“企业固危废数据专员”。这是原“产废数据分析专家”的扩展，资源ID、旧工作方法、模型和原业务口径保留。

可以交办：“整理这两个月的固危废记录，核对库存、清运资料和处置账单，准备检查资料，给我差异表及月度摘要。”六类方法可以单独选择或组合，默认答复和必要Excel，需要时才生成Word/PPT。

在能力→技能→“企业固危废数据专员 · 标准工作方法”→查看，可选择任何配套文件；点“复制为个人方法”，修改步骤、company.json字段映射、preferences.json提醒和输出配置、result.md模板，保存并发布，再点使用。库存周报示例：`methods=["inventory"]`、`capacityPercent="80"`、`differencesOnly=true`。副本保留来源资源、源版本及指纹，个人编辑不会改企业原版；标准包发布不会自动更新个人版本。

完整可分发包在`capabilities/waste-specialist`。上游为feng-liu-1994/workbuddy-finance-workbench 2.7.0，固定提交5689d65599357e50a814622640ace1656b45799e，MIT许可；完整Skill子树、25份提示、索引、安全说明和任务模板保留原字节，原入口归档。未迁入其侧栏应用、账户、数据库、备份系统。上游MCP仅打开财务界面，未当作对账执行工具。来源及逐文件SHA见references/source-manifest.json。

现有能力优先：文件/Office有界解析、受控计算、DataAnalysis全量月报、成果存储版本、身份授权和资源发布共享全部复用。本轮仅补经SHA批准的可移植行业处理器及个人编辑界面。脚本stdin/stdout，不读取目录、不联网、不写业务文件；员工修改脚本不会获得执行权。真实企业适配主要替换主数据、映射、合同、有效资料要求与连接配置。

模拟资料完全虚构：三车间、一般固废主/辅库和危废暂存区，2026-08/09同组业务；JSON与9表XLSX同源，合同和附件按编号关联。独立参考结果位于examples/expected-reference.json：产生3700→4500kg，账面1320kg/实盘1270kg/差异-50kg；8月废油账单多40元，9月缺车次/接收单位，最终金额待核；一般固废9月出库于10月2日接收，9月末未闭合。内部容量与账龄不作法定期限或合规结论。

本模拟企业业务API、申报API均未配置；使用授权文件，不伪装真实客户接口，不自动对外申报。其他企业现有MCP及其凭据范围保持，不自动绑定到本场景。

发布和公网使用检查结果见本轮交付记录；不重跑既有离线续作、历史格式和全系统权限矩阵。
