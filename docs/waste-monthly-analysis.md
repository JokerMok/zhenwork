# 业务口径与产废月度分析

基线为已验证 employee-experience-v4；本轮发布、定向公网验证及实际应用 SHA 见 PROJECT.md。使用合成样例验证通用能力，不代表真实企业生产口径或客户数据已验收。

管理员：AI资源管理 → 企业资源 → 工具 → 新建，选择计算工具并开启“业务统计口径”。填写指标含义、适用范围、业务节点、对象映射、允许单位与重复规则；保存草稿、检查版本、激活、按现有共享入口授权用户/部门/角色。创建人、变更、激活、停用及使用权限复用资源审计/ACL。员工不能用聊天更改正式定义。

员工：原会话上传 XLSX/CSV 并提出月度分析；助手使用结构化导入工具，当前会话出现“数据映射”。也可从文件页上传后打开映射，或点击已有文件旁的“数据映射”。查看样本、修改列绑定、明确月份与已发布口径，保存后从唯一的主输入框继续。映射模板个人私有；同结构可复用，不复制企业口径。

## 数据和计算

- 首版单个已选工作表：20 MiB原件、50,000条非空数据行、64列、10工作表；压缩包展开100 MiB/2,000条目、单元格4,000字符、单次60秒/CPU55秒/内存384 MiB、全Host同时1个解析或计算。超限拒绝，不截断。已有Core1/队列/空闲120秒不变。
- 预览前12条，类型为建议；完整计算重新读取固定版本原件，扫描全部记录。UTF-8/BOM优先，严格GB18030后备；不替换乱码。原件保留SHA256、版本、原始工作表与行号。
- 业务日期自然月（上海时区），记录ID粒度，按正式节点和对象映射。单位显式换算kg，逐条Decimal HALF_UP到所配小数位，再汇总。规则可选择同编号同内容保留首条或重复阻断；内容冲突总是阻断。合计、重复表头、撤销、其他节点、期间外等逐项记录排除原因。
- 无效日期、缺字段/单位、未知对象/节点、冲销、负值、无法重新计算的公式均阻断，无有效月报。公式仅支持已实现的同表算术、引用与SUM，重新计算，绝不使用旧缓存；其他公式需先在可信Office中重算并导出可核验明细。
- 原件/映射/口径/结果版本不可变关联。Word和Excel从一份验证结果生成，并重新打开检查数值与条数；Excel包含汇总、类别、来源、趋势、纳入明细、排除及异常、口径与来源，含真实数值单元格、公式缓存及原文版本链接。模型只获取必要汇总和有界问题列表，原始明细不默认发给外部模型。
- 趋势只表示已提供文件中的有效记录；缺生产量、价格、合同、费用和清运条件时，不能推导单位产废、降本或最优清运。测试口径和样例必须标注合成，不是客户生产验收。

## 权限、恢复和维护

Host私有控制区每员工 `data-analysis/` 保存导入、映射模板、计算结果与交付回执；100次导入、100个分析版本、总128 MiB，不自动清理业务历史。文件原件及成果版本继续采用OfficeStore现有256 MiB历史预算，纳入原备份/隔离恢复体系。只读列表/预览/历史不唤醒Core，没有新增常驻服务。

每次计算、重试、原文链接、成果预览/下载/恢复复核当前员工、输入原件和口径USE权限。停用/撤权或原件删除不能通过旧任务/版本绕过；旧报告不自动替换为新口径结果。若员工已下载，服务端不能收回其离线副本。

同文件/选项导入幂等；同原件/映射/口径/期间计算复用持久结果。变更映射或口径生成新分析标识，以精确十进制报告前后总量和差值，不改原始上传数据。成果生成重试复用已验证文件，失败时保留已有成功回执；文件被外部修改时停止，要求核实。全部交付成功后允许另存最多10组命名副本，保留固定结果和原版本；部分交付只能沿原路径重试缺失项。继续修改使用既有Office定点编辑/历史版本能力。检查工具同时返回原始数值与真实 numberFormat，不能因原始值没有末尾零而误修文件。基础预览按文件数字格式显示kg/吨小数位，记录数为整数；复杂格式仍以原文件为准。

沿用普通聊天TaskRunner后台执行、取消和恢复，不创建cron或第二套调度器。取消向受控解析子进程传递；崩溃后可重新执行纯计算，已成功文件通过哈希回执重用。恢复仅应用和配置，不等于回退数据库或业务文件。

## 本轮定向验证边界

- 普通员工经公网网页上传、预览、保存映射和已发布口径，从原聊天使用真实模型调用计算与双格式生成工具。BOM CSV和双工作表XLSX分别完整扫描6行，9月/产生/同ID同内容去重后3条，2150.000 kg（2.150000吨），A1350、B800；独立Decimal程序核对真实下载字节。XLSX含未缓存的 `=600+600`，按受支持公式重新求值。
- 另一151行文件只有12行预览，完整计算为151条/15.100kg；实际使用口径v2。五类异常在网页显示原始位置与原因，结果阻断、无虚假汇总；取消后不虚报完成。
- 修改重量列映射后2151.250kg，与旧版差1.250kg，原件不变；Word标题定点续改、历史恢复沿用原文件机制。管理员更新口径后旧报告固定v1及原哈希。重复导入复用原记录。
- 受控单个Excel输出失败保留成功Word；恢复后只补失败成果，Word原SHA/版本不变。关闭整个验收浏览器后服务器继续生成两份成果，重新登录原聊天取得完整结果及实际下载。
- 第二普通账号不能取得导入、结果、原件、预览、成果版本或操作他人任务。仅撤销专用合成口径共享后，旧分析和已生成成果的在线预览/下载被拒绝；重新授权恢复。
- 支持公式、GB18030、重复冲突、舍入、未知对象/单位、精确差值及预览精度使用定向程序检查补充；这部分不冒充全部已做网页故障注入。未做全历史、后台全巡检、压测、桌面或Microsoft Office客户端验收。

真实客户明细、企业最终正式口径和真实共享目录尚未提供。首版单个选定工作表、明示预算和受支持公式范围保持；不支持任意SQL、跨工作簿公式、通用BI或自动认定企业数据完整。合成验收满足功能发布条件，真实生产业务应用需先由管理员配置并确认正式口径。
