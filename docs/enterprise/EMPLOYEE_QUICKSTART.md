# 员工快速开始

1. 打开企业提供的工作台入口，登录并修改初始密码。
2. 新建任务，用一句话说明要做什么、资料范围和希望收到的成果。
3. 上传已获授权的资料；需要专业方法时选择对应专家。
4. 在聊天中查看执行过程。任务可取消，需要继续时使用继续/恢复。
5. 可以关闭页面，回来后在原聊天查看结果。
6. 打开文件预览，核对后下载；历史版本在文件记录中保留。
7. 继续在原聊天提出修改，点名原成果及需要调整的内容。
8. 在“能力 → 技能 → 查看 → 复制为个人方法”中修改步骤、字段和提醒，保存并发布后使用。企业正式方法不随个人修改而改变。

缺资料、单位不清或证据不够时，结果会标记待核。请补原始资料，不要求补造数值。看不到应有资料、模型不可用、文件反复失败或任务无法继续时，联系企业管理员。不要把密码或模型密钥写进聊天。
