# 销售演示

所有资料均为虚构，放在“示例资料/演示企业”，不与真实业务资料混用。开场说明：展示员工如何交付工作、查看依据、复核待核项和继续修改；不演示对外申报或付款。

| 演示 | 员工操作 | 复核重点 |
| --- | --- | --- |
| 通用办公 | 上传演示简报，提出“根据这些资料整理一份分析报告和 Excel” | 文件真实可打开；结论能回到资料；缺项不补造 |
| 固危废任务 | 选择数据专员，提出“整理本月固危废记录，核对库存、清运和处置费用，给我差异 Excel” | 明确虚构期间；差异、原始来源与待核条件一致 |
| 个人方法 | 复制标准方法为“我的库存周报”，修改提醒和输出要求，保存并发布，再指名使用 | 企业标准不变；个人配置确实影响输出；权限不扩大 |

演示无需新建行业能力。市场材料只使用已验证范围；性能引用 CAPACITY.md 的实际测量部分。模型调用需本企业授权配置，第三方连接未配置时如实说明。
