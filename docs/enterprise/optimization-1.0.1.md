## 关键边界

Java 服务仍是身份、资源、ACL 和版本的唯一权威。探针只读取已授权 Core 的发行元数据，不导入被检测包，不联网、不安装、不执行包内脚本。无法确认的依赖标为未验证。知识诊断没有向量召回或重排阶段，不虚构分数或去重结果。反馈缺失的历史版本保持未知，原因与结论须人工填写并附证据。个人草稿不会直接保存、发布或修改公司正式包。

## 数据和发布

新增 `0025_feedback.sql` 的三张反馈表，原 24 个迁移保持字节与哈希不变。应用回退需要明确审查对新增表的兼容性，保留数据，不回退数据库。部署沿用腾讯现有不可变 release、备份、迁移、切换和定向公网核验流程；原生 Core/Gateway 未改动，按原有镜像摘要复用。发布记录将在实测后更新。

## 对标与实现依据

- LibreChat：Skill 同步与包维护（`api/server/services/Skills/sync.js`）。
- DeepSeek Harness：固定插件、版本及运行过程组织。
- RAGFlow / MOVO：解析元数据、片段级来源选择及条款保留。
- Dify：反馈、运行记录和资源版本关联。
- OpenHands / AionUI：事件身份、流式归并和执行体验。

只借鉴交互与工程模式，未复制上述项目源文件。本轮产品实现、来源依据、隔离实测和公网核验以对应代码与发布证据为准。
