# ZhenWork Enterprise 1.0 RC1 产品边界

版本状态见同目录 ACCEPTANCE.md。功能沿用已验证业务版本，RC1 的安装与维护验证单独计列。

| 使用方 | 正式支持范围 |
| --- | --- |
| 员工 | 聊天任务、后台执行、取消/继续/恢复、上传/预览/下载与文件版本；Word/Excel/PPT；授权知识、专家、Skill/MCP/Tool；复制和调整个人方法 |
| 行业能力 | 固危废数据专员（原六类方法、强度/费用变化、换月和补证）、产品选型、政策查询与资料核查。按已授权数据执行，缺项保留待核 |
| 管理员 | 用户/部门/角色、RBAC/Data Scope、Provider/Model、Assistant/Skill/MCP/Tool/Knowledge、共享与撤回、企业配置、Branding、审计/用量、运行状态 |
| 部署 | Ubuntu 26.04 LTS、Linux x86_64、单机 Docker、PostgreSQL 17、Redis、Java 21、Node 24、HTTPS 双入口 |

限定支持：外部模型、连接器和企业知识需管理员配置并获得授权；Office 格式兼容按实际已验收链路使用；跨日期法规与合规问题保留适用限制，不自动代替法律裁决。

暂不支持：多租户 SaaS、Kubernetes、国产系统适配、任意数据库降级、自动申报/付款/业务系统写入、BI/CRM、预测、自动清运优化和自动议价。完全离线安装不作为首版标准承诺。

员工文件、会话和方法按当前权限访问；拥有旧链接不恢复已撤回授权。标准包升级不覆盖个人副本，个人旧版升级须显式操作。
