# 网页办公预览与交付连接

本轮实现将企业网页会话中的 Office 入口和工作区成果入口接到同一个本机 Host 预览路径；桌面 OfficeCLI 预览保持原路径。实际上线版本和业务验收以 PROJECT.md 和服务器 VERIFIED.json 为准，不以本文替代运行证据。

## 预览契约

`GET /enterprise/files/preview?path=...&sheet=...&start=...&version=...`：身份先经 RC2 复核，再读取当前员工 workspace 或该员工 runtime-temp/aionui 上传目录。历史版本只能来自当前员工的版本索引，不能传任意缓存文件。转换结束后复核身份及当前源 SHA，文件已变化则返回 FILE_CHANGED_RETRY。无公共第三方服务，无共享转换缓存，HTTP no-store。

- XLSX：工作表切换，每页100物理行、最多40列；合并单元格、列宽、基础字体/填充/对齐和常用数值格式。复用 Decimal 计算器计算支持的算术/SUM公式，不读取旧缓存作当前计算值；不支持的公式显示原式和警告。不是全功能 Office 编辑器。
- DOCX/PPTX：复用已有有界解析器，以段落、表格和幻灯片为位置分页显示正文。复杂版式、图片和图表下载原件查看。
- PDF、图片和 UTF-8 文本沿用浏览器私有二进制/文本预览，提供下载、错误重试与空内容反馈；Office旧格式明确不支持。25MiB Office预览上限与原文件50MiB存储/下载上限独立。
- 全Host同时一次转换，超出立即给出可重试状态；Python转换受超时和Linux384MiB地址空间/CPU时限约束。失败不影响原文件下载，也不在Host执行宏或用户文档中的代码。
- 打开时重读；Office面板每15秒在页面可见时检查当前SHA，源未变不重复转换，源变化重新生成；切换、关闭或退出取消旧请求。版本恢复刷新当前文件元数据；手动打开历史版本则固定对应版本。

## 任务与配置

工具回执展示本轮实际产物的预览、下载、继续修改入口；只有带校验SHA的成功回执建立成果入口。部分交付保留逐文件失败原因，提供只继续未完成步骤的输入，不由聊天文本推断全部完成。双文档生成按数据SHA和当前文件SHA持久记录成功项，同一数据重试复用已有成功项，数据或文件变化不静默覆盖。原始失败工具记录保留。

新建任务先在Core空闲时同步后台现有配置，再读取新助手详情、技能和MCP目录；完成之前不能发送使用旧配置的新任务。缺配置/刷新失败有明确提示和部署方配置的管理入口。正在运行的任务不在此路径内被强制刷新。各独立资源的现有授权、完整包安装、5秒撤权监测与执行前复核保留。

管理端知识上传入口更新为后台已经支持的 Office、PDF、扫描件、图片和文本格式，显示10MiB实际限制、索引状态及解析失败代码；版本预览使用内容最新版本号。没有引入新的知识库、调度系统或统计底座。

## 发布范围

`deploy/tencent/restage-web.sh` 从已提交SHA归档，仅允许Web/Host、指定管理资源页、对应测试/文档等变更；依赖锁变化、Java/control/Rust变化必须走完整stage。分别构建员工/管理网页与Host，按不可变manifest逐字节复用control-source、Java和精确amd64原生镜像；不得把旧员工网页标成新构建，也不得把应用回滚当数据库回滚。暂存不切换服务，仍经finalize一致性备份及迁移门禁后激活。

## 企业包撤权缓存

Core 的个人 Skill 删除 API 是软删除。网页 Host 在已管理企业包被停用、撤权或被替换后，还会清理该员工固定 Skill 命名空间和 `rc2-stage-*` 中的同名包文件；其它个人 Skill、工作区、成果和历史版本不进入清理范围。使用固定 Python 标准库程序、Linux 目录描述符、`O_NOFOLLOW` 和抗符号链接攻击的 `rmtree(dir_fd=...)`，不执行包内代码。清理失败不遗忘待撤销的 manifest 名称，并使该次运行环境准备失败；不把残留旧包当可用资源。清理受128MiB地址空间、5秒CPU和10秒进程超时约束。
