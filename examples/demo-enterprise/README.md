# 演示企业（完全虚构）

仅用于独立新企业安装及销售试用。上传 data/ 内文件至员工专属“示例资料/演示企业”；真实资料使用不同授权目录。不得用示例口径覆盖企业正式口径。

本例截至2026-11-02：账面库存150kg，盘点145kg、差异-5kg；合同独立核算172元，账单180元、差异8元。生产量未提供，不计算单位产废。这些结果来自资料和公式，不写入业务执行逻辑。

使用现有数据专员，指定输入JSON及截止日，交付差异Excel。需要默认使用演示口径时，管理员复制标准方法并在配置中明确设置演示企业、截止日和来源；不能改其他员工副本。销售三条脚本见 docs/enterprise/SALES_DEMOS.md。
