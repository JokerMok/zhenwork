# 回滚与 Cutover 后数据保护

状态：策略已选，演练 NOT_RUN。

采用 **Cutover Write Freeze + Forward Fix**，不假定旧 RC1 可表达 RC2 的统一资源版本、分享和模型权限。

迁移与试切换期间冻结写入，备份 RC1 数据库/卷及 RC2 目标数据库/卷；验证 RC2 后再开放写。若尚无 RC2 新写入，停止 RC2、恢复入口和 RC1 备份，核对原有账号/会话/文件/ACL 摘要后解除冻结。

一旦开放 RC2 写入，发现故障先重新冻结并做 RC2 增量备份，保留新增 User/Resource/Session/Message/ACL。此时默认 Forward Fix；不得直接启动 RC1 覆盖或遗弃新数据。若必须降级，应另行实现并验证逆向映射，明确 RC1 无法承载的资源隔离导出与暂停策略；当前不声称具备无损逆向迁移。

R16 实际演练包含：备份完整性、独立环境恢复、冻结边界、无新写入回退、存在新写入拒绝危险降级及 Forward Fix 恢复。检查备份加密、权限、哈希、引用、秘密和卷所有权。演练证据须注明该策略不等于任意时刻一键回到旧版本。
