# 员工与管理员使用说明

适用于当前候选实现。界面显示企业设置的软件名称，下文统一称“工作台”。本地及合成账号验证已完成的功能，不等同真实企业上线验收。

## 员工

使用管理员分配的邮箱和密码登录。新建或重置密码的账号先修改临时密码；不要共用账号。左侧提供“新建任务”“AI 助手”“企业知识”“我的文件”“历史任务”“历史对话”“我的审批”和“设置”。

在“AI 助手”选择可用助手，或从“新建任务”开始。提交时写明目标、输入材料和预期输出；需要引用资料时上传文件或使用已授权的企业知识。输出过程会显示进行状态，只有明确完成终态才算任务结束。遇到失败可按界面提示重试；中止后不会继续把旧任务视作成功。

历史任务属于当前账号。刷新后可查看已保存内容，继续操作仍需当前权限；管理员调整知识、助手或账号权限后，旧任务可能提示权限变化，此时新建任务并重新选择可用资料。不要反复复制旧知识片段试图绕过撤权。

导出等受控操作会显示审批卡，核对说明后选择允许或拒绝。每次审批只对当前操作有效，不代表永久授权。“我的审批”可以查看相关记录。

“我的文件”支持 TXT、MD、CSV、JSON、PDF、DOCX、XLSX、PPTX，每次最多 10 个、总计 20 MiB。解析结果取决于文件结构；当前不支持扫描件 OCR、加密 PDF、宏或嵌入对象。大文档建议由管理员进入知识库。上传检查不等同完整病毒检测。

企业知识只展示当前有权访问的内容。回答附带来源时打开引用核对原文；当前检索是分词和关键词匹配，不承诺语义召回。别人分享的来源链接不会自动授予权限。已看到或下载的内容无法远程收回，权限变化只控制后续访问。

使用完毕退出登录。若账号被禁用、登录被撤销或密码被重置，旧登录状态不再有效；联系企业管理员处理，不需要向其发送私人会话内容。

## 管理员

登录后进入 `/admin`。菜单按角色权限显示；看不到某项并不代表系统故障。管理员默认没有读取员工私人文件和会话正文的能力。

建议先建立部门和角色，再创建员工、配置助手及知识库。为员工分配最小必要权限；密码至少 12 位，新建或重置后要求首次修改。离职或暂停使用时停用账号并撤销登录。内置角色和最后管理员有保护规则，不能通过普通表单误删关键管理入口。

助手指定可用模型、角色、知识库和允许能力。模型设置只管理已部署的标识、启用状态和输出上限；Provider 凭据由部署人员在服务器安全配置，不在浏览器填写。能力页面只控制已有、已审查的能力，不能安装任意脚本或外部服务。

知识库上传后查看解析与索引状态，失败需检查文件类型或内容。授权可以按员工、部门、角色或企业配置；拒绝规则优先。文档可进一步缩小访问范围。助手关联知识库不等于员工自动获得读取权，检索与引用下载都会重新检查权限。管理知识库的权限也不自动授予读取全部文档的权限。

品牌设置支持软件名称、企业名称、Logo、深色 Logo、favicon、品牌色、登录文案、支持说明和版权。图片只接受 PNG/JPEG/WebP，单张不超过 256 KB 且像素总量不超过 1,048,576；不接受 SVG、HTML 或远程图片 URL。保存冲突说明另一个管理员已修改配置，刷新后核对再提交。

审计页面用于按条件检查管理操作和安全结果，用量页面按员工、部门或模型查看记录。缺少 Provider usage 的请求会明确标记覆盖缺失，不能据此推算准确费用。设置额度前确认统计周期与业务需求；额度不足会阻止新执行，不应通过换账号规避。

系统页面显示数据库迁移、执行状态、本地连接器关闭原因和最近成功备份。备份、恢复、升级由有宿主权限的部署人员按 [运维手册](deployment-runbook.md) 执行。页面显示备份成功不代表已经做过恢复演练。

## 当前边界

一个实例服务一家企业，没有 SaaS 租户、账单或租户切换。V1 本地连接器关闭，电脑目录不会被自动读取；所需材料通过 Web 明确上传。当前验证模型为已配置的豆包链路；未验证模型不应对员工承诺可用。正式启用前还需完成独立设备、真实 Linux AMD64、目标容量和发布 Gate。
